# AURORA — English-first GEIPAN archive localization (5 Nov 2026)

## Public-language policy

The live AURORA experience is **English-only**. This applies to actual case descriptions, not merely labels and menus. Archived original documents remain accessible in their source language via cited HTTPS links.

A read-only desktop/mobile visual inspection caught the discrepancy: French original GEIPAN witness narratives appeared as `summary.en` and `story.en` on English dossiers and archive cards. This was not an English translation and could repeat the witness narrative twice. U.S. National Archives/Project Blue Book records were already English.

## Completed data transformation

- Ingested source: UAPDrop's CC BY 4.0 compilation of original CNES GEIPAN reports.
- **2,715 GEIPAN records**: all retain their original `original_language:"fr"`, authoritative source links, date, source provenance, geographic metadata, status, and original French summary/story in `.fr` fields.
- **2,713** report summaries and stories have a machine-generated English translation from the published original using local Helsinki-NLP/opus-mt-fr-en, created offline on the owner's ROCm GPU.
- **2** source records contain only one non-descriptive character (E or *), so no eyewitness narrative exists to translate. They now display an English explanation of the source limitation. Do not invent observation details.
- **7,317** English National Archives records and **101** curated dossiers are untouched.
- The public bulk index and full dossier shards share identical English summaries and translation status. This is not editorially verified fact-checking: `translation.editorial_reviewed:false` appears in machine-translated records, and the dossier text discloses it.
- No private Supabase Auth, Cloudflare D1 report, moderation data or user account was read or modified by this localization.

The deterministic CLI is `scripts/translate-geipan-to-english.py`. It requires a locally installed PyTorch ROCm/CUDA, transformers and sentencepiece, and an accessible Hugging Face model. The script is deliberately **not** part of automatic CI generation and refuses to overwrite existing translations. It requires all 64 source shards and exact original record-ID mapping. See `tests/geipan-english-only.test.mjs` for the invariant check.

**Regression prevention:** `scripts/import-uapdrop-records.mjs` refuses a write that would silently destroy the machine English translations. A future changed upstream dataset must be rebuilt in an isolated staging tree, independently retranslated/checked, then released as an atomic reviewed change to index + all 64 shards.

### Translation accuracy and uncertainty

This is translation, not a claim that any reported object was extraterrestrial. Classification, historical dates, map anchors and original source links are preserved and not generated by the model. As with all automated translation, there can be errors: refer to the original French source for exact wording, and favor a manual review when quoting the report. Source content originally in French can include ambiguities, missing detail and accounts that GEIPAN later classified as identified.

## Completion pass — 5 November 2026

An additional translation pass over the last 17 GEIPAN records found 15 French narratives and 2 source records containing only a single character. All 15 narratives have English machine translations; the other two display an honest English source-limitation statement. The French original, source links, dates, classifications and geographic metadata remain unchanged.

Invariant: all 2,715 GEIPAN public dossiers have English display text, 2,713 machine translated and 2 source_text_insufficient. The remaining 7,317 Blue Book and 101 curated records are unchanged. This is 100% English UI coverage, not a claim that empty originals can be translated or that machine translation received editorial proofreading.
