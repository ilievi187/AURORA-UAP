# V1.8 moderation: staging and security gates

This route is disabled by default. It must not be presented as production ready until the configuration and security checks below are completed. It cannot publish cases.

The owner is the sole moderator. `/moderation.html` is a static shell; `/api/moderation/` serves private reports only after verifying the Cloudflare Access JWT signature against the team's certificates, issuer, application audience, expiry, and the exact moderator email. It also requires the production hostname and a separate enable flag. Review POST requires same-origin JSON and writes an audit record. The page renders report text as text, not HTML. Never put tokens or secrets in this repository.

Before enabling: create a Cloudflare Access self-hosted application whose protected paths cover BOTH `/moderation.html` and `/api/moderation/*` and whose policy allows only the verified moderator. Restrict bypass paths, require strong authentication, and verify the actual configuration; origin JWT validation remains mandatory even with Access. Set the actual Access team URL in `AURORA_ACCESS_TEAM`, the application audience in `AURORA_ACCESS_AUD`, and the exact moderator email in `AURORA_MODERATOR_EMAIL`, all in production Pages variables. Set `AURORA_MODERATION_ENABLED=enabled` only after an independent security review and tests. Redeploy, verify unauthenticated requests and preview-domain requests fail, and verify an authenticated moderator can review a synthetic report and see an audit event. Test forged, expired, wrong-audience and wrong-user tokens, cross-origin POST, no-store headers, and failure when keys cannot be fetched. Do not test with real personal information. An approved review remains quarantined; publication needs a separately authorized, redacted workflow.

The first queue shows the 100 latest submissions; pagination, deletion/retention procedures, reliable notification delivery and independent review remain release gates. Do not enable intake until those operational needs, a reviewed policy and tested privacy contact are ready.
