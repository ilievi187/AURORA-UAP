# AURORA — international case dossier enrichment and publishing

## Source archive (101 public cases)
The reference archive contains 101 source-linked public case files. Each entry keeps the publisher's original URLs, date, source attribution and published geographic precision. It is **not** the private D1 observation-submission database.

- The source collector preserves original English narrative material where a publisher supplies it; it must not turn missing evidence into invented interviews or make reports more certain than the underlying documents.
- Geographic markers display named source localities. An airport, London, a town centre or a regional centroid is an **approximate map anchor**, not a measured position or flight track. Unknown/redacted locations stay unpinned. The original detailed source coordinate explanation is available in each dossier's expandable *original source location note*.
- When a source's English description is copied into a field labelled Bulgarian, the runtime rejects it as a translation. The source material remains visible as clearly labelled English until a real translation is available.

## Activate automatic translation for the public archive in 18 languages
The client, endpoint `/api/archive-translation?id=<public-case-id>&lang=<locale>&detail=1`, and edge caching are already implemented. Automatic translation **requires** an active Cloudflare Pages Workers AI binding. No guessed translation is displayed.

1. Cloudflare dashboard → **Workers & Pages** → Pages project `aurora-uap`.
2. **Settings** → choose the **Production** environment → **Bindings** → **Add** → **Workers AI**.
3. Name the binding **`AI`** (uppercase). Repeat for Preview if needed. Redeploy from `main`.
4. Open a real public case in German, Bulgarian or another locale. A successful API response reports `"status":"translated"` or `"status":"original"` and includes source-attributed title, summary and, with `detail=1`, all narrative paragraphs. When the binding is absent, the endpoint returns HTTP 503 with `"status":"unavailable"` rather than fabricating translation.
5. Check Workers AI requests and billing; the platform translates per-demand and serves cached responses afterward. Translation is not free/unlimited and must be monitored.

Cloudflare binding reference: https://developers.cloudflare.com/pages/functions/bindings/

**Do not add a new `wrangler.toml` without exporting the current Pages settings**: Cloudflare treats the file as the source of truth and it can override existing configuration. This is why the current PR intentionally does not alter Pages bindings or deploy secrets.

## Original photos and video within AURORA
- A source video is embedded only if the publisher offers a permitted official player or the project has explicit verified hosting/reproduction rights. Click-to-load and one player at a time preserve user choice; publisher-restricted video remains a direct original-source link.
- Image links must not be indiscriminately downloaded or re-hosted. The dossier shows original imagery inline only when `photoPreview()` receives explicit, verifiable rights metadata; otherwise it offers the source link.
- Every dossier now shows a thematic cinematic cover where there is no cleared image; it is **explicitly labelled an AURORA illustration**, not an incident photograph.
- For an approved original image, add `media[].preview` metadata (verified `rights_status`, `hosting_permission`, allowed `authorization_type`, image `url`, `rights_evidence_url`, attribution and license URL when required). The dossier renderer will show it without rewriting the media UI.
