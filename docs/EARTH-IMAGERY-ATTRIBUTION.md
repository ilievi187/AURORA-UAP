# AURORA — photographic Earth assets / attribution

## Earth day, night, clouds, specular and normal maps

- Files: `assets/earth/earth-day-4096.jpg`, `earth-night-4096.jpg`,
  `earth-clouds-1024.png`, `earth-specular-2048.jpg`, `earth-normal-2048.jpg`
- **Origin of planetary maps:** Solar System Scope / INOVE, https://www.solarsystemscope.com/textures/
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/
- The source describes NASA-derived global imagery and other data. These are edited
  composite **visualizations, not live satellite photographs or evidence for UAP claims**.
- **Redistribution mirror:** the Three.js example texture collection,
  https://github.com/mrdoob/three.js/tree/master/examples/textures/planets
  These example assets include resized and merged material channels.
- **Modifications in AURORA:** repackaged under descriptive filenames, uploaded to
  WebGL as sRGB visual maps, downscaled on mobile for memory/performance; combined
  with physically motivated sun lighting and a separate simulated atmosphere.
- The previous hand-painted polygon map remains available only as a technical
  fallback if the photographic assets fail to load.
- No endorsement by NASA, Solar System Scope or Three.js is implied.
